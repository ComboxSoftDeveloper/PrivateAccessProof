# PrivateAccessProof

Замеры к статье «А чё, так можно было? Приватное поле за 0,25 наносекунды» —
доступ к приватным членам чужого типа: рефлексия, скомпилированное дерево
выражений, метод из инструкций IL и `UnsafeAccessor` из .NET 8.

BenchmarkDotNet 0.15.8, Release, .NET 8, .NET 9 и .NET 10 в одном запуске,
со снятием машинного кода.

Статья: [«А чё, так можно было? Приватное поле за 0,25 наносекунды»](https://habr.com/ru/articles/1080538/)

## Что проверяется

| Раздел | Что смотрим | Что сравнивается |
| --- | --- | --- |
| 1 | чтение приватного поля со строкой | прямой доступ, рефлексия с поиском и без, дерево выражений, IL, `UnsafeAccessor` |
| 2 | запись в приватное поле | рефлексия, дерево выражений, IL, `UnsafeAccessor` |
| 3 | приватное поле значимого типа | упаковка у рефлексии против её отсутствия |
| 4 | вызов приватного метода | рефлексия, делегат, `UnsafeAccessor` |

## Как воспроизвести

Нужны SDK .NET 8, 9 и 10: BenchmarkDotNet поднимает по процессу на рантайм.

```
dotnet --list-sdks
```

В пути к проекту не должно быть запятых и точек с запятой. BenchmarkDotNet
собирает вспомогательный проект и передаёт путь в MSBuild без кавычек, тот
разбирает эти знаки как разделители списка свойств и падает с MSB1006.
Отчёты при этом снимаются нормально, а замеры молча не выполняются.
Батник проверяет путь и останавливается сразу.

Весь прогон одной командой:

```
all.bat
```

Вручную, без скрипта:

```
dotnet run -c Release -f net10.0 -- checks
dotnet run -c Release -f net10.0 -- failure
dotnet run -c Release -f net10.0 -- --filter *
dotnet run -c Release -f net10.0 -- --filter *ReadBench*
```

Аргумент `noasm` выключает снятие машинного кода.

Причина любого сбоя записывается в `Bdn\PrivateAccessProof.log`.

## Как устроен замер

Все измеряемые методы лежат в `Subjects.cs`, у каждого `NoInlining`.

У всех способов подготовка вынесена за пределы замера: описание поля найдено
один раз, дерево выражений скомпилировано, метод из инструкций IL собран,
делегат создан. Всё это делается в статическом конструкторе `Reflectors`.

Отдельным вариантом замеряется рефлексия с поиском поля на каждом обращении.
Так писать не надо, но именно так её чаще всего и применяют, поэтому вариант
в таблице есть. В сравнении с `UnsafeAccessor` он не участвует.

Прямой доступ изнутри типа взят опорой: быстрее уже не будет, это обычное
чтение поля.

Для поля значимого типа замер отдельный. Рефлексия возвращает `object`,
поэтому число упаковывается, и это видно в столбце Allocated.

Для структуры первый аргумент метода доступа объявлен по ссылке. Без этого
доступ достался бы копии, и запись потерялась бы. Сверка это проверяет.

Имя члена в `UnsafeAccessor` задаётся строкой. Отчёт `failure` показывает,
что бывает при опечатке: сборка проходит, а при первом вызове летит
`MissingFieldException`. Рефлексия в той же ситуации возвращает `null`,
и проверить это можно сразу.

## Что проверялось и чем

| Что проверялось | Чем |
| --- | --- |
| Все способы читают одно значение | отчёт `checks` сравнивает пять способов с прямым доступом |
| Запись доходит до объекта, а не до копии | отчёт `checks` читает поле после записи каждым способом |
| Статические члены доступны так же | отчёт `checks` проверяет статическое поле и статический метод |
| У структуры нужен первый аргумент по ссылке | отчёт `checks` пишет в поле структуры и читает результат |
| Опечатка в имени ловится в рантайме | отчёт `failure` показывает тип исключения |
| Поиск члена не попадает в замер | всё готовится один раз в статическом конструкторе |
| Упаковка учтена | столбец Allocated в разделе 3 |
| Дело не в сборщике мусора | режим `DOTNET_gcServer=1` |
| Дело не в конкретной машине | четыре машины, выгрузки всех четырёх в `Results` |
| Дело не в конкретной версии | .NET 8, 9 и 10 в одном запуске |

Все замеры сняты на x64 под Windows.

Дизассемблер на Linux требует установленного `perf`. Выключается аргументом
`noasm`.

## Границы

Числа в этом файле взяты только из отчётов. Отношения посчитаны из исходных
значений, а не из округлённых.

`UnsafeAccessor` не отменяет проверок доступа при сборке чужого кода: он
снимает их только у того метода, который объявлен с этим атрибутом.

Ссылки на исходники .NET даны на тег `v10.0.0`, коммит зафиксирован: `main`
уедет, и номера строк перестанут совпадать.
